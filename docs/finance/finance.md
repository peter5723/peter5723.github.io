# 金融知识

## 央行加息和减息会导致什么？

调整利率，影响的是两方面：贷款的利率和存款的利率。

如果利率提高，那么借钱的人贷款更贵，还款压力更大；而存钱的人享受到更高的利率也就更加愿意储蓄。企业也需要贷款来扩张，所以加息会导致企业扩张的门槛提高。这样来说，企业就更难招更多的人，招聘也就减少。大家更加愿意进行储蓄，那么消费也就变少了。消费变少，需求降低，因此物价也就降低，所以呈现一种通货紧缩的趋势。通货紧缩，即购买力增强，本国货币升值。需求降低，未来预期变差，股价承压。总体说来，加息是降温操作。

反之，如果利率降低，那么人们就不愿意将钱存到银行里，而贷款压力也下降了，于是人们更愿意消费或者投资，企业也更好融资。企业扩张，那么就会促进就业。人们愿意消费，这样消费的需求增大，物价也就升高，所以就更容易通货膨胀，货币购买力降低。需求升高，未来预期变好，利好股市。故而，降息是升温操作。

## 汇率的变化会导致什么？

汇率主要是影响进出口。

假设原先 1美元=7人民币
变成 1美元=6人民币：人民币升值，同样的钱能买更多美元。
变成 1美元=8人民币：人民币贬值，同样的钱只能买更少美元。

本币升值，能换更多的外币，那么也就能购买更多外币的东西，所以进口量就变多。出去旅游、留学等也更便宜。但是相对的，外国人的外币相当于贬值，他们只能买到更少的本国的东西，因此出口就会受到冲击。

主动贬值则有利于出口，但是会降低海外购买力，提高进口成本和外币还债成本。

## 通货膨胀和通货紧缩

通货膨胀会带来什么问题？钱的购买力下降，物价上涨了。良性的膨胀伴随着工资的上涨，但是当工资的涨幅涨不过物价，就会导致生活水平下降，反而进一步恶化消费。

通货紧缩一般带来的是商品变便宜了。但是也可能会导致这样的恶性循环：

```
需求不足 -> 企业降价 -> 营收和利润下降 -> 降薪裁员 -> 人们消费欲望更低 -> 需求进一步下降。
```

因此货币的价值需要控制。
